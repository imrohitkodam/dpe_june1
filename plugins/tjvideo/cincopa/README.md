Cincopa  integration with shika


Step 1 : 
Create an account in cincopa https://www.cincopa.com/
Then you can go to the gallery section:  click on gallery or https://www.cincopa.com/media-platform/wizard_edit15

Click on create button right side top and choose any template.
Click on save and next and upload file. your gallery will be created.

Step 2:
FInd the key :
https://www.cincopa.com/cincopamanager/api    click on this link  you will get a key which will be used into our joomla cincopa plugin.


How to add Key in Cincopa

Click on plugins and search for cincopa then click on cincopa and add the cincopa api key in the Secret Key text box.
