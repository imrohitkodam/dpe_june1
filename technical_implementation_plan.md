# Technical Implementation Plan

---

## Phase 1 – Report Storage & Ownership

- Store AI report, `form_id`, `user_id`, form snapshot JSON, and SHA-256 snapshot hash.
- This allows future comparison and audit tracking.

---

## Phase 2 – Download Tracking

- Track report downloads using `is_downloaded` and `last_downloaded_at` fields.
- Change detection should only notify for reports that have been saved/downloaded.

---

## Phase 3 – Change Detection

On form save:

1. Load reports linked to form.
2. Generate current snapshot hash.
3. Compare with stored hash.
4. Mark report as stale if different.
5. Store field-level differences.

---

## Phase 4 – Notifications

- In-form warning banner.
- Outdated badge in reports list.
- Optional email/in-app notification.
- One-click regenerate report action.

---

## Database Design

| Column             | Type           | Purpose               |
|--------------------|----------------|-----------------------|
| `report_id`        | BIGINT PK      | Report ID             |
| `form_id`          | BIGINT         | Linked UCM Form       |
| `user_id`          | BIGINT         | Generated By          |
| `snapshot_json`    | JSON           | Form Snapshot         |
| `snapshot_hash`    | VARCHAR(64)    | Change Detection Hash |
| `status`           | ENUM           | active / stale        |
| `is_downloaded`    | BOOLEAN        | Download Tracking     |
| `created_at`       | TIMESTAMP      | Generation Time       |

---

## SQL – `ai_reports` Table

```sql
CREATE TABLE ai_reports (
    report_id         BIGINT AUTO_INCREMENT PRIMARY KEY,
    form_id           BIGINT NOT NULL,
    user_id           BIGINT NOT NULL,
    snapshot_json     JSON NOT NULL,
    snapshot_hash     VARCHAR(64) NOT NULL,
    ai_output         LONGTEXT,
    status            ENUM('active', 'stale') DEFAULT 'active',
    is_downloaded     TINYINT(1) DEFAULT 0,
    last_downloaded_at DATETIME NULL,
    created_at        DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

---

## SQL – `ai_report_field_diff` Table

```sql
CREATE TABLE ai_report_field_diff (
    diff_id    BIGINT AUTO_INCREMENT PRIMARY KEY,
    report_id  BIGINT NOT NULL,
    field_name VARCHAR(255),
    old_value  TEXT,
    new_value  TEXT,
    changed_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (report_id) REFERENCES ai_reports(report_id)
);
```
